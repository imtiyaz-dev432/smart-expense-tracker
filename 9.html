§ Concepts Reinforced Today

Eight patterns that came up repeatedly — each one a mental model worth internalizing.

1 str(None) = "None" — the silent data corruption

Python's str() always returns a string — including "None" for None. So str(x).strip().lower() after a null check never sees None again. Always null-check before converting to str.

Correct order: raw = data.get(k) → if raw is None: ... → value = str(raw).strip().

2 is not None does not protect from non-string types

{"x": 123} is not None → passes the check → 123.strip() → AttributeError. To handle any type safely: str(raw).strip(). Now 123 becomes "123" → validation rejects → 400 (not 500).

3 PATCH field guards — if "field" in data:

Assignments must be inside the guard, not outside. person_name = data.get("person_name") or "" at the top level, then borrow.person_name = person_name unconditionally — wipes the field when the client didn't send it. Silent data loss.

4 Silent no-ops — validation without assignment

The bug pattern that keeps coming back: if "amount" in data: raw = data.get("amount"); try: float(raw); except: return 400 — valid but never assigns subscription.amount = amount. Response says "success" but DB unchanged. Tests catch this in seconds. Manual review can miss it for 3 rounds.

5 Aware vs naive datetime arithmetic

loan.due_date is timezone-aware (column has timezone=True). datetime.utcnow() is naive. Subtracting them raises TypeError. Always use datetime.now(timezone.utc). Bonus: utcnow is deprecated in Python 3.12+.

6 Field names must match the model exactly

Borrow.type vs Borrow.borrow_type. Loan.status == "completed" vs "closed". These are silent killers — they throw AttributeError (500) or silently filter everything to zero. Grep your model file before writing query filters.

7 Return outside loops, single response shape

Dashboard had return inside a for loop, breaking three scenarios: no loops, loops with no matches, and loops with partial iteration. Always accumulate inside the loop, return after it. And avoid conditional response shapes — always include all fields, use zeros when there's no data.

8 Decimal serialization — the recurring snake

Sixth time this week. sum() aggregates return Decimal. jsonify() can't serialize it. Every GET route with a numeric aggregate needs float(). Consider adding a project-wide helper: def money(v): return float(v or 0).
